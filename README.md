I design electronics end to end — **schematic → PCB → assembly → firmware → cloud app** — and ship them as real products.
Self-taught, building hardware since 2020, with an ITI Electrician background, so I am as comfortable with 230V wiring as with a microcontroller datasheet.

Under **Edge Tech Lab** I build smart-home boards, custom PCBs and firmware for makers and small businesses.

## 🔧 What I work on

- **Embedded firmware** — ESP32 family (ESP32-C3 / S3), Arduino and ESP-IDF, FreeRTOS, OTA updates
- **PCB design** — schematic capture, 2-layer layout, mains-isolated power stages, assembly and bring-up
- **IoT** — ESP RainMaker, MQTT, BLE provisioning, Google Assistant and Alexa integration
- **Edge AI** — camera-based detection with custom YOLO models on RDK X5 (BPU-accelerated pipelines)
- **Power and mains** — relay switching, isolated SMPS, energy metering (BL0942)

## 🚀 Featured project

### [HA-4CH Smart Switch](https://github.com/chandan-singh-edgetech/HA-4CH-Smart-Switch)
ESP32-C3 4-channel smart switch: app, Google Assistant / Alexa voice control, wall-switch sync, power-cut memory and over-the-air updates.
Designed, assembled and tested by me — now sold by Edge Tech Lab.
